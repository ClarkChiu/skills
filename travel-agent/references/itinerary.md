# 行程節奏、動線與飲食

這份是 SKILL.md §3「順暢度審查」那一支的正典——沒有可對帳的標準，審查就只會產出「整體節奏尚可」這種空話。

## 一、每日骨架

**先定骨架，再往裡面填點。**骨架由氣候與體力決定，不由「想去的地方有幾個」決定。

- 熱帶／雨季的預設骨架：**上午戶外 → 午後室內 → 傍晚戶外**（理由與雨季規則見 `calendar-weather.md`）。
- 高溫目的地的正午（約 11:00–15:00）視同「不可用於戶外」，跟下雨同級。
- **每天只排一個「主錨點」**（一個需要體力或需要準時的項目），其餘都是可加可減的衛星。主錨點超過一個，任何一個延誤都會骨牌。

## 二、體力曲線

1. **連續高強度日不得超過兩天**，第三天必須是低強度（睡到自然醒、步行範圍內、可隨時中止）。
2. **抵達日與離境日不算完整日**（回推方法見 `transport.md` 第一節），且**不排不可退、不可改期的預約**。
3. **抵達日一律低強度**：入境通關＋領行李＋進市區＋等入住已經吃掉半天，而且是時差與疲勞最重的時候。把「辦網卡、換錢、熟悉環境」這類行政事項排在這天就已經是滿的。
4. **有夜間場次的那天（表演、夜市、酒吧），白天要對應減量**——夜場的真正成本是隔天早上。
5. **同行者的體力上限以最低的那位為準**，不是平均（SKILL.md §0 每趟必問）。

## 三、動線

1. **同一天的點要收在同一區**，跨區移動當成獨立成本項（車程＋車資＋叫車等待），一天最多一次跨區。
2. **禁止折返**：A 區 → B 區 → 回 A 區的動線要重排。審查時把每天的點按地理順序列出來，一眼就看得到折返。
3. **跨區移動固定排上午**（雨季暴雨時段與晚尖峰都會讓車程翻倍，見 `calendar-weather.md`、`transport.md`）。
4. **步行距離要標數字**，不要寫「很近」。超過 15 分鐘的步行在高溫高濕地區等於一個活動。

## 四、餐點堆疊（最常被忽略的一種過載）

1. **同一天不排兩頓重口味／高油／吃到飽**——第二頓會吃不下，等於白排一個名額還花了錢。
2. **正餐之間要留 4 小時以上**；下午茶、咖啡、甜點算「半頓」，堆三個半頓等於一頓。
3. **一天最多一個「需要空腹去」的行程**（吃到飽、多道式、市場小吃巡禮）。
4. **必比登／名店排隊時間要算進當天預算**，不是餐費預算而是時間預算。
5. **當地飲食的重量要看**：湯麵類連吃三天會膩，行程要穿插不同型態（湯／飯／輕食／異國料理）。

## 五、緩衝配額

- **每天至少留一段 60–90 分鐘的空白**，不指定用途。沒有空白的行程表，第一個延誤就會傳導到最後一項。
- **需要準時的項目（表演、預約、接送）前面要有緩衝**，而不是緊接在另一個活動之後。
- **緩衝不是「休息時間」**——休息要另外排。把緩衝當休息用，等於沒有緩衝。
- **「最脆弱的一環」要用「錯過了會少掉什麼」定義，不是用「看起來很緊」定義。**
  問自己：這個環節失敗，行程實際上會損失什麼？答不出來，它就不是脆弱環節，是多餘環節，該刪。
  > 反面範例（熊野 2027 初稿）：我把「走完古道後搭公車去某個站牌」標成全程最脆弱的一環，
  > 但那個站牌是隔天早上的起點、當晚還要住回原處——**錯過那班車的後果是零，還早兩小時到**。
  > 真正沒有備案的兩處（隔天早上的兩段轉車、要準時的遊船）反而一個字都沒寫。
- **反過來也要檢查：宣稱「有緩衝」的那一天，是不是其實最需要別人給它緩衝。**
  一天裡有「需要準時的預約」加上「三段以上接駁」，那天就是消耗緩衝的一天，不能拿來當緩衝。

## 六、飲食限制的落地做法

§0 問到的飲食限制，要轉成這些具體動作（不是問完就算）：

1. **過敏原做成當地文小卡**（手機截圖＋紙本），寫清楚「不能吃什麼」而不是「我對某某過敏」——後者需要對方理解成分表。
2. **查該地料理的隱藏成分**：東南亞的魚露、蝦醬、蠔油、花生幾乎無所不在；素食者要查當地的「素」是否包含蔥蒜、是否用高湯。
3. **訂位／訂餐時就講**，不要現場才說——名店與多道式餐廳現場改不了。
4. **生水與冰塊的判準**：連鎖店與正式餐廳的製冰多為淨水製、可接受；街邊攤與散裝冰塊避開。判準是「店家型態」不是「看起來乾不乾淨」。
5. **慢性病用藥**連動 `customs-culture.md` 的管制藥入境規定與 `onsite.md` 的就醫管道。

## 七、順暢度審查的檢查表（§3 那一支直接照這個問）

逐日回答，答不出來就是問題：

- [ ] 這天的骨架是什麼？高風險時段（正午／午後雨）排的是室內還是戶外？
- [ ] 這天有幾個主錨點？超過一個嗎？
- [ ] 這天的點按地理順序排出來，有沒有折返？跨區幾次？
- [ ] 這天的正餐間隔幾小時？有沒有兩頓重口味？半頓堆了幾個？
- [ ] 這天有沒有 60–90 分鐘的空白？需要準時的項目前面有緩衝嗎？
- [ ] 這天的戶外項目有沒有步行 5–10 分鐘可達的室內替代方案（含名稱地址營業時間）？
- [ ] 抵達日／離境日：可用時間回推過了嗎？有沒有排到不可退的預約？
- [ ] 連續高強度是否超過兩天？
- [ ] 有夜場的隔天，白天減量了嗎？
- [ ] **這天有沒有寫出「幾點」？**幾點起床、幾點吃早餐、幾點出發、搭幾點的車、幾點會到、幾點入住。
      **一格都沒有的話，那不是行程，是地名串。**
- [ ] **這天中午吃什麼？**在有供餐住宿之間移動的日子，午餐是最常被整段忘掉的一餐——
      山區、離島、國家公園裡常常整段沒有商店。要寫成**訂房時的必辦事項**（例：加購便當），
      因為多數這類住宿是預付制、事後補不了。
- [ ] **這天的步行時間有沒有乘上團體係數？**官方標示時間是給一兩個人、不含長休息的估值；
      多人同行取決於最慢那位，加上等人、拍照、補水，實務抓 **1.2–1.3 倍**。

⚠️ **最後三項是 2026/8 才補上的，因為它們同時被漏掉過一次。**
一份「每天寫了去哪裡、看起來很完整」的行程，可以完全沒有時刻、沒有午餐、
而且所有時間都是單人值——**三個洞加起來就是現場會餓著肚子站在站牌前的那份行程**。
