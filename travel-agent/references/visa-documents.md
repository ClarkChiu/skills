# 簽證與證件

這個領域的失敗多半是**不可逆且在機場才發現**：填錯不能改、錯過期限不能補、口岸選錯直接遣返。紀律的重點不是「記住規則」，而是「每趟重查、填表前逐欄核對」。

## 一、找到官方網站（最容易被詐的一步）

1. **每趟出發前重新確認當期官方網址，不要用書籤、不要點搜尋結果第一名。**官方網域會換，且搜尋結果前幾名長期被代辦與釣魚站買廣告佔據，外觀高度仿冒官網。
2. **用機械化判準辨識官方站**：網域必須是目的地政府後綴（`.gov.xx` / `.go.xx`），且官費金額等於官方公告金額。**任何自稱「官方授權代辦平台」的都不是官方**——「政府認證」「官方合作夥伴」是最常見的話術。
3. **正確入口是我國駐外館處官網或外交部領事事務局的連結**，從那裡點進去，不要自己搜。也可用「駐外館處 × 目的地移民局官網」交叉比對同一條連結。
4. **官方站可能同時有多個合法網域**（同系統不同網址），這不代表其中一個是假的——但兩個都必須是政府後綴。
5. 山寨站收官費的 2–8 倍，除了溢收還有個資與信用卡外洩風險；有的收完錢無人回應也不退款。
6. **用代辦不是罪，但要看清楚買的是什麼**：代辦價 = 官費 + 服務費，且官費金額必定與官方公告一致。**任何「比官費便宜」的都是詐騙訊號。**急件代辦確實有價值（來不及自辦時），但你必須能拆分官費與服務費才知道自己是被服務還是被騙。

## 二、填表（付款後不能改，一次填對是唯一策略）

1. **付款前，逐欄位對著護照念一次再送**：姓、名、護照號碼、生日、國籍、入境日期、出境日期、入境口岸、Email。「送出後不可自行修改、費用不退」是 e-簽系統的常態設計，退件通常不會告訴你錯在哪。
2. **姓名照護照資料頁的英文拼法打，姓／名不可對調。**連字號的處理有單一決策順序：**預設照護照逐字打（含「-」）；只有當系統拒絕特殊字元、或明示要用空格時才改半形空格**，並把實際送出的字串截圖存證（報到或移民官問起時可對照）。理由是部分系統不接受特殊字元或以 MRZ 比對，不是「護照上就沒有連字號」。
3. **入境口岸是硬條件**：填的口岸必須等於實際入境的那一個。**同一城市常有「機場」與「海港」同名選項**——選錯時移民官依法可直接拒絕入境並遣返，而且是在你已經飛到當地才發現，現場無法補救。
   - ⚠️ 選項的**實際字面**要在填表當下目視確認，不要照網路教學找。教學常寫「挑含 IATA 代碼那一列」，但官方下拉選單裡可能根本沒有 IATA 代碼，照著找會找不到而誤選。
4. **效期區間往前後各抓幾天**：起算日填在實際入境日之前、迄日填在實際離境日之後（在該簽證最長效期內）。填得剛好等於機票日期＝把行程鎖死，改班機、延誤、提前一天出發全部作廢，只能重辦重繳。
5. **國籍欄位的字面要實查**：臺灣在各國系統裡的條目字面不一（可能排在 C 開頭而非 T），網路教學說法互相矛盾。以官網下拉選單當下的實際選項為準，**行前文件不要寫死答案**——表單會改版，寫死一個過時答案比不寫更糟。
6. **信用卡先開通海外／國際線上交易**，否則付款失敗會讓申請卡在中途，而本人以為已送件。

## 三、期限回推

1. **工作天要扣「目的地的國定假日」，不是臺灣的假日。**先查目的地當年度假日行事曆，再往前推，再乘上「退件重辦一次」的緩衝。移民局是政府機關，當地連假整段停擺；旺季與大節前後審核時間會從數天拉長到 7–10 天。
2. **官方標示的工作天不是從按下送出鍵開始算。**常見設計是「收齊資訊**且**收到費用之日」起算，而費用往往是拿到申請編號之後才繳——回推時要把「送出 → 拿到編號 → 完成繳費」這段也算進去。
3. **退件不退費**：把「一次填對」當唯一策略，不要把重送當備案。

## 四、落地簽的誤解

**看到「落地簽」先問一句：是不是要先拿到核准函（Visa Approval Letter）？**對臺灣護照，多數國家的所謂落地簽是「行前先取得核准函 → 落地後蓋章繳費」，不是「到了再辦」。沒有核准函，**出發地航空公司櫃檯就不讓你登機**。代辦廣告用「落地簽」當賣點，實際賣的是核准函服務費；自由行走 e-簽永遠更便宜、更少變數。

## 五、核准之後

- **一定印彩色紙本，每人一份、單面列印，最好兩份**（一份報到、一份移民官），再存手機＋雲端。報到櫃檯與移民官都可能查驗紙本；手機沒電、機場網路不穩、官員拒看螢幕的情況都真實發生過。這是零成本的保險。
- **入境前線上申報（arrival card／QR）已是東南亞常態**，且各國**分機場、分梯次**上線——同一國家不同機場規則可能不同。每趟行前重查：有沒有、哪些機場已上線、可提前幾天填、完成後的 QR 截圖＋列印。官方公告與部落格資訊常落後，出發前一週要重驗一次。
- **健康申報類規定會隨公告開關切換**：可能法規已生效但主管機關同時澄清「常態下一般旅客不必預填」。這種規定不能套用兩個月前查到的結論，出發前一週必重驗。

## 六、護照本身

1. **「剩餘效期六個月」是國際慣例，不是普世規則，更不一定是目的地的法定要求。**以「目的地官方 × 航空公司」雙查為準。
   - 目的地法規可能寫的是「護照效期須比簽證到期日多 N 天」這種完全不同的門檻；申根區多數國家要求「離開日之後仍有 3 個月效期」；部分國家只要求入境當日有效。
   - 反向也成立：效期不足六個月時，**航空公司仍可能自行套用六個月標準刁難**（OTA 開的電子機票也常印這句），所以「法規不要求」不等於「不會被擋」——行前查一次搭乘航空公司的規定。
2. **簽證頁至少留 2 頁空白**（入出境章各一）。快滿就換發，不要賭。（註：多數國家的空白頁要求無官方明文，屬實務通則。）
3. **證件備份走三軌**：雲端（護照資料頁、簽證 PDF、保單、電子機票、訂房確認）＋紙本一份放託運行李＋紙本一份隨身，**紙本與護照正本分開放**。單一備份等於沒備份——護照被扒走時隨身包裡的備份會一起消失，所以必須物理分離。
4. **護照正本鎖飯店保險箱，隨身帶影本＋簽證紙本**。治安風險高的目的地，護照是扒竊與搶劫的目標之一。
5. **改過名字或剛換發新護照**：機票、訂房、簽證上的英文姓名必須與**新護照資料頁**一致。外文別名只能用加簽保留，不能拿來當機票名。
6. **未成年同行先查護照效期**：未滿 14 歲的護照效期通常只有成人的一半（臺灣為 5 年，遺失補發者 3 年）。家長常以為「上次辦過就還有效」。

## 七、海外遺失護照 SOP（行前就寫進行程文件，不是出事才查）

```
當地警局報案取報案證明 → 最近的駐外館處 → 二選一：
  (a) 當地補發新護照（作業以工作天計，短行程等不到）
  (b) 申請入國證明書（專門讓你先回得了臺灣）
→ 短停留一律選 (b)，回台再補發
```

行前先備好 2 吋白底照片電子檔、身分證與護照資料頁影本，可以省掉半天。

## 八、其他機場會查的事

- **報到櫃檯會查三樣**：有效簽證或免簽資格、護照效期、**回程／續程機票**。單程票飛需簽證國家＝高風險。旅客被拒絕入境時載運的航空公司要負責送回並承擔罰則，所以櫃檯查得比你想像嚴。財力證明實務上少查，但移民官保有要求的權力。
- **停留期限以入境章上印的到期日為準**，不是自己數天數；落地當天算第 1 天是常態。**出關前把入境章拍下來**——逾期停留即使 1 天都會留下不良紀錄，章上日期是唯一有法律效力的依據，事後爭議只有照片能救你。
