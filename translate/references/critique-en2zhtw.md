# 批評清單：EN → zh-TW

精翻第三步用。逐段對照原文檢查初稿，只列問題不改寫。

> **邊界**：本清單抓「英文結構殘留在中文裡」的翻譯腔。AI 生成腔（內容灌水、三段式、AI 詞彙、罐頭開場白）歸 `humanizer`，MUST NOT 在此收錄該類規則——發表前要去 AI 味，翻完接著跑 humanizer。

## 1. 準確性

- 事實、數字、日期、專有名詞逐段與原文對照。
- 漏譯（原文有、譯文沒有）、增譯（譯文自己長出來的）、改義（意思偏了）。
- 術語是否全篇同一譯法、是否符合 `01-analysis.md` 術語表。
- 專業術語首次出現有沒有括號附原文。

## 2. 翻譯腔（每條附壞例 → 改法）

- **「進行了…」動詞化**：對系統進行了優化 → 優化了系統。
- **「…性／…度」名詞化堆疊**：具有高度的可擴展性 → 很能擴充。
- **被動濫用（被／由／受到）**：這個問題被工程師解決了 → 工程師解決了這個問題。中文被動留給真正的受害義（被騙、被裁）。
- **連接詞堆疊**：段段以「因此」「然而」「此外」開頭 → 砍虛連接詞，靠語意銜接。
- **代名詞冗餘**：當你設定你的路由器時 → 設定路由器時。中文省略主詞是常態。
- **長定語塞爆**：一個由三個模組組成的用於處理封包的系統 → 這個系統有三個模組，負責處理封包。拆句。
- **英文語序直搬**：作為一個工程師，我認為… → 我是工程師，我認為…（"as a..." 開頭慎用）。
- **比喻逐字譯**：檢查原文的比喻與慣用語是不是譯了字面、丟了意圖。

- 逐一過 SKILL.md 的詞彙層（user-dictionary → glossary → terms-en-zhtw）。
- 抓中國用語混入：軟件→軟體、視頻→影片、信息→資訊、網絡→網路、服務器→伺服器、默認→預設、調用→呼叫、質量（quality 義）→品質。
- 單位、數字、日期格式照臺灣慣例。
