# 精翻四步詳則

每步讀上一步的檔、產出自己的檔。輸出目錄規則見 SKILL.md（檔案旁 `<basename>-<方向>/`；對話貼文則中間檔進系統暫存區）。

## 第一步：分析 → `01-analysis.md`

通讀**全文**（長文也是——這步不分節），產出：

```markdown
## 內容摘要
[核心論點、作者立場與寫作脈絡、原文目的與目標讀者]

## 術語表
| 原文 | 譯法 | 來源層 |
|---|---|---|
[全文抽出的專有名詞、技術術語、反覆出現的說法；逐一過 SKILL.md 的詞彙層
（user-dictionary → glossary → terms-en-zhtw → 一般慣例），標注取自哪一層；
四層都沒有的寫自己的判斷並標「新」]

## 語氣評估
[正式或口語？幽默、比喻、文化引用？對目標讀者該用什麼語域？]

## 翻譯難點
- [詞／段落] → [難點類型：理解落差／比喻慣用語／長句雙關] → [建議策略：意譯／替換／保留＋註]
```

## 第二步：初稿 → `02-draft.md`

照 `01-analysis.md` 的術語表與策略翻譯全文，套 SKILL.md 的六條翻譯原則。長文按標題分節翻、依序合併，逐節對照原文段落。

**快翻升級路徑**：使用者對既有快翻結果說「繼續精翻」時，把快翻產出原樣存為 `02-draft.md`（MUST NOT 重翻），補做 `01-analysis.md` 的術語表與難點段，然後直接進第三步。

## 第三步：批評 → `03-critique.md`

對照原文逐段檢查初稿。**這一步只診斷，MUST NOT 內含任何改寫後的全文或整段重寫**——產出是問題清單，不是譯文。

依方向載入對應清單逐條檢查：EN→zh-TW 用 `critique-en2zhtw.md`，zh-TW→EN 用 `critique-zhtw2en.md`。

```markdown
## 準確性
- [問題]：[位置（段落／行）] — [描述]

## 翻譯腔／中式英文（依方向）
- [問題]：[原句摘錄] → [建議修法（一句話，不是整段改寫）]

## 用語與語域
- [加註／刪註／換詞]：[詞或段落] — [理由]

## 統計
[嚴重問題 X 項、建議改善 Y 項；整體評估一句話]
```

## 第四步：重翻 → `04-final.md`

讀 `02-draft.md`＋`03-critique.md`，**逐項**回應批評：修正所有準確性問題、重寫被點名的不自然句、調整註釋。然後整篇通讀最後檢查：

- 當成獨立文章讀，像不像目標語言原生寫的？
- 敘事語氣前後一致？節間銜接順暢（長文分節翻的接縫處特別看）？
- 術語全篇一致？markdown 格式完整保留？

完成後照 SKILL.md 給下游建議（chinese-typography 正規化／humanizer）。
