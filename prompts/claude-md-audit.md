# CLAUDE.md／設定自我稽核 — 規則衛生提示

**用途**：週期性掃過 CLAUDE.md／全域設定／各 skill，揪出可刪規則、衝突、冗餘、模糊指令，
**只回報、不改檔**，由你逐項核可。對抗「規則越積越多 → AI 同時協調無關/矛盾指令 → 輸出變差」。

**怎麼用**：手動貼進對話直接跑；或由內建 `schedule` 週期執行（接線見 `prompts/README.md`）。
**語言**：報告用臺灣繁體中文。**這份提示是起點不是聖旨，最後刪不刪由你決定。**

來源：判準 1–5 改寫自 @itsolelehmann（X）的 self-audit 提示；判準 6–7 為本設定專屬補充
（可攜鏡像結構）；可檢驗化改寫法則參考 dev.to 的「5 patterns」。詳見 `prompts/README.md`。

---

```
在回答之前，先完整讀取我的所有設定：CLAUDE.md、~/.claude 全域設定、skills 資料夾中每一個
SKILL.md 與 references、context 檔案，以及任何你找得到的指令檔。

接著逐條審查你找到的每條規則／指令／偏好，對每一條回答這 7 個判準：

1. 這是你不需要被告知就會預設執行的行為嗎？
   ⚠️ 防呆：要區分「與預設重複（可刪）」和「刻意覆寫預設（保留）」——我的語氣、反對協議、
   語言慣例、用詞對照是故意的偏好覆寫，即使影響預設行為也不算冗餘，別標刪。
2. 這條與我設定中他處的規則衝突或矛盾嗎？
3. 這條與另一條規則或另一個檔案重複了嗎？
4. 這條看起來像是為了修正某一次特定糟糕輸出而臨時加的，而非為了整體改善？
5. 這條模糊到每次解讀都可能不同嗎？（例：「更自然一點」「用好的語氣」）
   → 對每條模糊規則，順手做「可檢驗化改寫」：先問「光看輸出，我能不能判斷你有沒有照做？」
     不能就改寫成可檢驗版——用祈使句（never／MUST），每個禁令都附替代做法
     （例：「不要用模糊歸因」→「指名出處或標『推測』」）。
6. 〔本設定專屬〕這條指到的檔案／旗標／skill／日期是否已失準？（指到不存在或改名的東西；
   該寫絕對日期卻寫相對；「上次同步」標記已過期）→ 失準的規則比沒規則更糟。
7. 〔本設定專屬〕這條是某真相來源的鏡像副本嗎？（行為準則鏡像自全域、術語表鏡像自
   user-dictionary.json）若是且已與來源漂移 → 標記為鏡像、提議對齊來源，別把副本當正本改。

最後提供（臺灣繁體中文、只輸出報告、不修改任何檔案）：
- 建議刪除清單：每條附一行理由＋它命中哪個判準＋信心(高/中/低)
- 各檔案之間的衝突清單（衝突攤開、不要折衷成「平均」規則；建議保留較新/較常用那條，標另一條待清）
- 健康摘要：規則總數中通過 vs 被標記的數量；CLAUDE.md 行數 vs ~150–200 行目標；
  正規則:負規則比（健康值 ≥ 2:1——禁令太多代表沒給夠「該怎麼做」）
- （可選，需我另外要求才給）去除冗餘後的精簡版 CLAUDE.md
  —— 我的設定是刻意結構化、可攜的，預設只給「外科手術式逐條增刪清單」，整份重寫我要求才給

規則：缺證據就標假設、不瞎掰；任何刪改都等我逐項核可。
```

3 種任務測——品質維持/變好＝刪對了；某任務變差＝只把那一條加回去。
